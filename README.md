## Kurulum
`index.html` dosyasını tarayıcıda açın. GitHub'da yeni bir public repo oluşturup tüm site dosyalarını kök dizine yükleyin. Settings → Pages → Deploy from a branch → main / (root) → Save. Çıkan adresi buraya ve rapora yazın.

## Önemli tamamlanacaklar
- Projeler sayfasındaki dört kartın GitHub ana sayfası linklerini gerçek proje depolarınızla değiştirin. Çalışmalarınızın gerçekten mevcut olduğunu kontrol edin.
- Proje ekran görüntülerini kendi çalışmalarınızdan ekleyin.
- İletişim sayfasındaki profesyonel profil bağlantılarını kişiselleştirin.
- 3 ekran boyutunda gerçek ekran görüntüsü alın ve rapora ekleyin.
- Form demo amaçlıdır; sunucuya mesaj iletmez.

## Teknoloji ve gizlilik
Statik HTML, CSS ve JavaScript; harici kütüphane/analitik yoktur. Tema tercihi tarayıcı localStorage alanında tutulur. Form verileri gönderilmez.
